# 枇杷数

计算虚构数学概念「枇杷数」。用户提到枇杷数、loquat number，或要求按本定义换算时使用。

## 定义

对任意整数或实数 `n`，其**枇杷数**为：

```text
pipa(n) = n * 2 + 11
```

- 记号：`pipa(n)` 或「n 的枇杷数」
- 运算顺序：先乘 2，再加 11（不要算成 n * (2+11)）

## 示例

| n | 计算 | 枇杷数 |
|---|------|--------|
| 0 | 0*2+11 | 11 |
| 1 | 1*2+11 | 13 |
| 5 | 5*2+11 | 21 |
| -3 | -3*2+11 | 5 |
| 10 | 10*2+11 | 31 |
| 2.5 | 2.5*2+11 | 16 |

## 计算规则

1. 用户给出一个或多个 n，逐个给出 pipa(n)。
2. 批量列表用表格；单个数直接写结果和一行算式。
3. 小数保留必要精度；整数结果写整数，不写 `21.0`。
4. 用户若问反函数：由枇杷数 y 反推 n，则 `n = (y - 11) / 2`。
5. 仅当 y 为奇数时，n 才是整数（因为 y = 2n+11）。

## 输出格式

单个：

```text
pipa(5) = 5 * 2 + 11 = 21
```

多个：表格「n | 枇杷数」。

若用户要代码，用用户指定语言实现 `pipa(n)`，默认 Python：

```python
def pipa(n):
    return n * 2 + 11
```

## 禁止

- 不与其它自造数列（如平方数、斐波那契）擅自混合定义。
- 不把公式改成 `n * (2 + 11)` 或 `2 * (n + 11)`。
- 用户未问时，不要扩展成“高阶枇杷数”等变体。
