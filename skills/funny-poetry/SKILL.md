# 搞笑诗词

用格律或仿格律写幽默、荒诞、自嘲式诗词。在用户要“来点好笑的诗/词/打油诗”“沙雕文案”“押韵吐槽”时使用本技能。

## 核心原则

1. **先好笑，再像诗**：笑点优先于平仄；近体壳可以破，韵脚尽量稳。
2. **反差制造笑料**：雅词写俗事、宏大叙事写鸡毛蒜皮、古典意象写现代社畜。
3. **具体胜过抽象**：“PPT 改到第九版”比“工作很累”好笑十倍。
4. **结尾要抖包袱**：末句反转、自黑或点题，避免前头铺垫长、结尾泄气。

## 常用套路

- **打油诗**：五言/七言，押韵宽松，口语入诗，一韵到底。
- **戏仿近体**：外壳像绝句/律诗，内容离谱；可故意三平调、出韵并自我吐槽。
- **词牌整活**：《如梦令》短平快适合段子；《西江月》上下片对仗适合“理想 vs 现实”。
- **仿古新编**：改写名句（“床前明月光”→加班版），保留原节奏。
- **日程体**：把起床、通勤、开会、摸鱼写成组诗。

## 主题库（可混用）

| 方向 | 可写点 |
|------|--------|
| 打工 | 周一、加班、需求变更、绩效、外卖 |
| 学习 | 考试周、论文、图书馆抢座 |
| 生活 | 减肥失败、熬夜、快递、相亲 |
| 科技 | 内存不足、更新失败、AI 抢活 |
| 自嘲 | 秃头、懒、穷、社恐 |

禁止人身攻击、歧视、低俗擦边；幽默对准普遍处境或写作者自己。

## 技法

- **大词小用**：“征程”“史诗”“丰碑”配奶茶、修图。
- **小词大用**：用奏折体写给猫铲屎。
- **数字夸张**：“改稿三十遍，甲方仍说再看看”。
- **古今混搭**：文言虚词 + 现代名词（“呜呼，deadline 迫矣”）。
- **顶针/复沓**：加强洗脑节奏。
- **留白自嘲**：不解释笑点，让读者自己品。

## 结构模板

**七言打油（推荐默认）**

```text
起：交代场景（一句）
承：加码倒霉（一句）
转：突然离谱/升华（一句）
合：包袱或自嘲（一句）
```

**《西江月》整活（进阶）**

- 上片写“当年壮志”
- 下片写“如今惨状”
- 过片处对比要狠

## 输出格式

1. 标题可无厘头但别太长（10 字内为佳）。
2. 正文分行；若用词牌写明词牌名。
3. 可加一行“【梗】”点出笑点来源（可选）。
4. 用户只要文案时，去掉说明只留正文。

## 禁止

- 不堆网络烂梗（“绝绝子”“YYDS”）超过一处。
- 不为搞笑牺牲可读性：韵至少读起来顺。
- 不连续输出同结构同韵的流水线诗；换场景换节奏。
- 不把严肃悲剧事件拿来消遣。
